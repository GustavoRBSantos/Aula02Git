Laboratório de Git e GitHub via Terminal

Projeto acadêmico desenvolvido para praticar conceitos de versionamento de código utilizando Git e GitHub, com foco em fluxos profissionais via Terminal.

Sobre o Projeto

O repositório consiste em um ambiente de testes voltado para o aprendizado prático de Git e GitHub.

Diferente de projetos tradicionais focados em uma aplicação final, este projeto foi estruturado para simular situações reais de desenvolvimento, permitindo explorar e validar comandos, fluxos de trabalho e boas práticas de versionamento.

Durante o processo, foram realizados testes com criação de arquivos, alterações de código e simulações de desenvolvimento apenas como suporte para o uso do Git.

Tecnologias e Ferramentas Utilizadas

* **Versionamento:** Git
* **Repositório Remoto:** GitHub
* **Interface:** Terminal (CLI)
* **Linguagem de apoio:** C#
* **IDE:** Visual Studio Community 2022

Padrão de Branching e Engenharia de Software

Para demonstrar domínio no uso do Git, o desenvolvimento seguiu práticas utilizadas no mercado:

* A branch principal **`main`** representa o ambiente estável
* Cada teste ou experimento foi realizado em branches isoladas (`feat/teste`, `chore/organizacao`, etc.)
* Os commits foram padronizados utilizando a especificação internacional *Conventional Commits* (ex: `feat:`, `chore:`, `fix:`)
* As branches temporárias foram deletadas localmente e remotamente após a realização bem-sucedida do `git merge`

Como Executar o Projeto

Para clonar este repositório e explorar os testes realizados:

```bash
# 1. Clone este repositório
git clone https://github.com/GustavoRBSAntos/Aula02Git.git

# 2. Acesse a pasta do projeto
cd Aula02Git
```

Objetivo de Aprendizado

Este projeto foi desenvolvido com o objetivo de:

* Praticar o uso do Git via terminal
* Compreender o fluxo de trabalho com GitHub
* Aplicar boas práticas de versionamento
* Simular um ambiente de desenvolvimento profissional
